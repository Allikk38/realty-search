Профессиональный каталог контактов отделов продаж жилых комплексов Новосибирска и области. Поддерживает **новостройки** и **загородную недвижимость**.

## ✨ Возможности

### Основной функционал
- 🔍 **Умный поиск** по застройщику, ЖК, менеджеру или телефону
- 🧠 **Нечёткий поиск** (расстояние Левенштейна) с автоподсказками

- 🌓 **Светлая/тёмная тема** с сохранением в localStorage
- 📄 **Пагинация** (20 застройщиков на страницу)
- 🔤 **Алфавитный указатель** (А–Я) для быстрой навигации
- 📊 **Живая статистика** — количество застройщиков, ЖК и контактов
- 💾 **Кэширование данных** — работа в офлайн-режиме
- 📋 **Копирование телефонов** одной кнопкой

### Технические особенности
- ✅ **PWA поддержка** — можно установить на телефон как приложение
- ✅ **Service Worker** — кэширование ресурсов и fallback при офлайне
- ✅ **Google Sheets API** — данные синхронизируются из таблицы
- ✅ **XSS защита** — все данные экранируются
- ✅ **LocalStorage кэш** — резервное копирование данных
- ✅ **CORS поддержка** — корректная работа с внешними API

## 🔧 Настройка Google Sheets

### 1. Создайте таблицу со следующими столбцами:

| Застройщик | Название ЖК | Адрес ЖК | Адрес ОП | Общий телефон | Менеджер | Телефон менеджера | Должность | Категория |
|------------|-------------|----------|----------|---------------|----------|-------------------|-----------|-----------|
| Расцветай | Эко-квартал на Кедровой | ул. Кедровая 80/1а | | +7(383) 255-88-22 | Данил Швец | +7 961 873-63-10 | менеджер | newbuild |

**Примечания:**
- `Категория`: `newbuild` (новостройки) или `suburban` (загородная)
- Можно добавлять любые другие столбцы — они будут проигнорированы

### 2. Разверните Apps Script:

1. Откройте вашу таблицу → **Расширения → Apps Script**
2. Вставьте следующий код:

```javascript
function doGet(e) {
  const corsHeaders = {
    'Access-Control-Allow-Origin': '*',
    'Access-Control-Allow-Methods': 'GET, OPTIONS',
    'Access-Control-Allow-Headers': 'Content-Type'
  };
  
  try {
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    const data = sheet.getDataRange().getValues();
    
    if (data.length < 2) {
      return ContentService
        .createTextOutput(JSON.stringify([]))
        .setMimeType(ContentService.MimeType.JSON)
        .setHeader('Access-Control-Allow-Origin', '*');
    }
    
    const headers = data[0];
    const result = [];
    
    for (let i = 1; i < data.length; i++) {
      const row = data[i];
      const obj = {};
      for (let j = 0; j < headers.length; j++) {
        let cellValue = row[j];
        if (cellValue instanceof Date) {
          cellValue = Utilities.formatDate(cellValue, Session.getScriptTimeZone(), 'dd.MM.yyyy');
        }
        obj[headers[j]] = cellValue || '';
      }
      result.push(obj);
    }
    
    return ContentService
      .createTextOutput(JSON.stringify(result))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader('Access-Control-Allow-Origin', '*');
      
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ error: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader('Access-Control-Allow-Origin', '*');
  }
}
```

3. Нажмите **Сохранить** → **Развернуть → Новое развертывание**
4. Выберите тип **Веб-приложение**
5. Установите доступ **"Все, у кого есть ссылка"**
6. Скопируйте URL веб-приложения
7. Обновите `GOOGLE_SHEETS_URL` в `script.js` и `pages/main.js`

## 🎨 Кастомизация

### Изменение темы по умолчанию

В `app/index.html` найдите блок:
```javascript
if (!localStorage.getItem('catalogTheme')) {
    localStorage.setItem('catalogTheme', 'dark'); // dark или light
}
```

### Настройка пагинации

В `pages/main.js` измените:
```javascript
this.perPage = 20; // Количество застройщиков на странице
```

### Добавление своих стилей

Стили разделены на:
- `style.css` — глобальные стили для поисковой страницы
- Встроенные стили в `app/index.html` — для каталога

## 🔄 Обновление данных

### Автоматическое (рекомендуется)
Данные загружаются из Google Sheets при каждом посещении. Кэш обновляется раз в 24 часа.

1. Отредактируйте `data.csv`
2. Сохраните в UTF-8
3. Залейте на сервер

## 🐛 Известные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Данные не загружаются | Проверьте CORS в Apps Script и URL веб-приложения |
| Не работает офлайн | Очистите кэш браузера и перезагрузите страницу онлайн |
| Не переключается тема | Удалите localStorage.setItem('catalogTheme') вручную |
| Ошибка Service Worker | Откройте DevTools → Application → Service Workers → Unregister |
