# realty-search
# 🏢 Каталог застройщиков Новосибирска

Поиск и управление контактами отделов продаж ЖК.  
Поддерживает **новостройки** и **загородную недвижимость**.

## Возможности

- 🔍 Поиск по застройщику, ЖК, менеджеру, телефону
- 🧠 Нечёткий поиск (расстояние Левенштейна) + подсказки
- 🤖 Интеграция с YandexGPT для семантического поиска
- 🌓 Светлая / тёмная тема с сохранением
- 📄 Пагинация (20 застройщиков на страницу)
- 🔤 Алфавитный указатель (А–Я)
- 📊 Админ-панель для редактирования CSV
- 📥 Импорт / экспорт CSV и Excel

## Быстрый старт

```bash
git clone https://github.com/[ВАШ_НИК]/realty-search.git
cd realty-search
Откройте index.html в браузере — никаких зависимостей, чистый HTML/CSS/JS.

Структура проекта
text
